# Security Policy

## Reporting a Vulnerability

V-LAW is a security tool. We take vulnerability reports seriously.

**Please do not open a public GitHub issue for security vulnerabilities.**

Report privately to: girish@getvvault.com

Include:
- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Your suggested fix (optional)

We will respond within 48 hours and coordinate disclosure.

## Scope

- V-LAW backend (Python/FastAPI)
- V-LAW tray app (Electron)
- Windows installer (Inno Setup)

## Out of Scope

- The AI agents V-LAW monitors (Claude Code, Cursor, Copilot)
- Your local operating system
